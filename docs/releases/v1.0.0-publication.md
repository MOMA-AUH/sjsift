## Fresh channel installation

```bash
conda create --yes --prefix "$WORK/channel-env" --override-channels \
  --channel conda-forge --channel bioconda MOMA-AUH::sjsift=1.0.0
conda list --prefix "$WORK/channel-env" --explicit
```
